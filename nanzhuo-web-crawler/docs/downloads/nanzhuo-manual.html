文字蜘蛛 · 使用说明书

在自己选定的网页文字上，体验抓取、翻转、反色、扭转、拉伸与回弹。

版本 v1.0.0 · 适用浏览器：电脑端 Chrome / Microsoft Edge
本文可保存到本地，双击 HTML 文件即可离线阅读；也可通过浏览器打印功能保存为 PDF。

一、第一次安装

  1. 下载并完整解压安装包。保留解压后的 web-crawler-extension 文件夹。里面应能看到 manifest.json。
  2. 打开浏览器扩展管理页。Chrome 地址栏输入 chrome://extensions；Edge 输入 edge://extensions。打开“开发者模式”。
  3. 加载解压后的文件夹。点击“加载已解压的扩展程序”，选择包含 manifest.json 的 web-crawler-extension 文件夹。请选择文件夹，不要选择 ZIP 或它的上层目录。
  4. 固定到工具栏。在右上角“扩展”菜单中找到“文字蜘蛛”，将它固定到工具栏，方便以后开启。

解压目录需要保留。移动目录后，需要从新位置重新加载扩展。本版提供可直接加载的扩展文件，尚未发布到扩展商店。

浏览器官方说明：Chrome 安装指南 · Edge 安装指南。

二、在自己的网页上使用

打开目标网页，点击工具栏上的蜘蛛图标，再选择一种开启方式：

  • 在当前网页开启：作用于当前主页面正文中的普通文字、标题、链接和代码。
  • 点击选块：移动鼠标查看高亮范围，点击想要互动的段落、代码块或内容区。
  • 拖拽框选：按住鼠标画出一个至少 100 × 100 像素的矩形，松开即可启动。只作用于矩形内的完整文字片段。

选择过程中按 Esc 取消。框选范围绑定网页坐标，滚动时跟随内容移动；网页布局大幅变化后，建议重新框选。

三、调整效果与控制

弹窗中可选择混合效果、抓取抬起、翻转反向、颜色反转、扭转摆动或拉伸挤压，并调整速度、互动力度与蜘蛛大小。脚尖接触文字以及腿部扫过文字都会触发互动。

网页右下角的控制条可以暂停、切换自动游走 / 跟随指针、选择接触效果，以及关闭并恢复网页。收起控制条后，可在扩展弹窗里点击“显示控制条”重新显示。

操作快捷键
暂停 / 继续Alt + Shift + S
关闭并恢复Alt + Shift + X
取消选择Esc

设置保存在本机浏览器中。每个标签页分别运行；切换到新标签页不会自动开启。刷新或导航后，需要手动再次开启。

四、使用本地 HTML 文件

在扩展管理页进入“文字蜘蛛”的“详细信息”，开启“允许访问文件网址”。再用同一个浏览器打开本地 HTML 文件，点击蜘蛛图标启动。

五、支持范围与恢复

本版支持普通网页主页面中的文字。浏览器设置页、扩展商店、内置 PDF 阅读器、跨域 iframe、图片 / Canvas 内的文字和 Shadow DOM 内容不参与文字互动。

输入框、表单控件和可编辑区域会跳过。网页编辑器若把内容放在可编辑区域，可选择阅读视图或预览区。

扩展运行时会临时给文字加入包装与动画样式；关闭时撤销，保留原字符与链接。部分依赖精确文字节点结构的动态网页可能需要刷新恢复，建议优先选择正文或阅读区域。

六、常见问题

加载时提示找不到清单文件

确认选择的是直接包含 manifest.json 的 web-crawler-extension 文件夹，而不是 ZIP 文件或解压后的上层目录。

开启后没有效果

确认当前打开的是普通网页，页面里有可见文字，选择范围足够大。若打开的是本地 HTML，请先开启“允许访问文件网址”。刷新后需要再次开启扩展。

说明书下载后怎么打开

双击下载的 HTML 文件，即可用浏览器离线阅读。想要纸质或 PDF 版本时，可使用浏览器“打印”功能。

七、隐私

扩展只使用 activeTab、scripting 和 storage 权限。点击扩展后才访问你选定的网页；动画、图标和互动都在本机运行，不向服务器发送网页文字或截图。
