# 文字蜘蛛浏览器扩展

在你选定的 Chrome / Edge 网页上运行。无需修改网页代码，也无需启动服务器。脚尖抓住真实文字，腿部扫过也会触发抓取、翻转、反色、扭转、拉伸和回弹。

## 第一次安装

1. 将 ZIP 完整解压，保留 `web-crawler-extension` 文件夹。
2. Chrome 地址栏输入 `chrome://extensions`；Edge 地址栏输入 `edge://extensions`。打开“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择含有 `manifest.json` 的 **web-crawler-extension 文件夹**。不要选择 ZIP，也不要选择上层文件夹。
4. 在浏览器右上角“扩展”菜单中找到“文字蜘蛛”，将它固定到工具栏，便于打开。

可参考 [Chrome 官方安装说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked) 和 [Edge 官方安装说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)。解压目录需要保留，移动目录后需要重新加载扩展。

## 在自己的网页上使用

打开目标网页，点击工具栏中的蜘蛛图标，选择一种方式：

- **在当前网页开启**：作用于当前网页正文内可见的普通文字、标题、链接和代码。
- **点击选块**：移动鼠标查看高亮范围，点击想要作用的段落、代码块或内容块。
- **拖拽框选**：拖出一个至少 100 × 100 像素的矩形，松开即可启动，只作用于框内的完整文字片段。

选择过程中按 Esc 取消。框选范围绑定网页坐标，滚动时跟着页面内容移动；大幅改变布局后重新框选。

网页右下角会出现控制条：可以暂停、切换自动游走 / 跟随指针、选择接触效果，以及关闭并恢复网页。收起控制条后，可以在扩展弹窗中点击“显示控制条”重新显示。

弹窗中还能调整速度、互动力度和蜘蛛大小。设置保存在本机浏览器中。每个标签页的动画分别运行，切换标签页不会自动把效果加到新网页上。刷新或导航后，需要再次开启。

快捷键：**Alt + Shift + S** 暂停 / 继续；**Alt + Shift + X** 关闭并恢复。输入框、表单控件和可编辑区域不会被自动拆分。

## 本地 HTML 文件

在扩展管理页打开文字蜘蛛的“详细信息”，开启 **允许访问文件网址**，然后用同一个浏览器打开本地 HTML，再点击扩展启动。

## 支持范围

支持普通网页的主页面内容。浏览器设置页、扩展商店、内置 PDF 阅读器、跨域 iframe、Canvas 图片内的字，以及 Shadow DOM 内的内容不在本版的文字互动范围内。网页编辑器若把内容放在可编辑区域中，会跳过该区域；可选择其阅读视图或预览区。

扩展会临时给文字加入小型包装，关闭时撤销包装和样式，保留原字符与链接。部分依赖精确文字节点结构的动态网页可能需要刷新恢复，建议优先选择正文或阅读区域。

仅使用 `activeTab`、`scripting` 和 `storage` 权限，点击扩展后才访问你选定的网页。所有动画代码和图标都在本地，不向服务器发送网页文字或截图。这里提供的是可直接加载的扩展源文件，尚未发布到扩展商店。

## 文件

- `manifest.json`：浏览器扩展配置。
- `popup.html` / `popup.css` / `popup.js`：扩展弹窗。
- `background.js`：当前标签页操作与本机设置。
- `content.js`：点击选块、框选和网页控制条。
- `engine.js` / `page.css`：蜘蛛及文字接触效果。
- `icons/`：本地图标。
- `安装指南.html`：可双击打开的图文安装说明。
