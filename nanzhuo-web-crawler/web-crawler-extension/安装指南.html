WEB CRAWLERS / BROWSER EDITION

把蜘蛛放到自己的网页上。

一次安装，以后打开想要的网页，点击蜘蛛图标就能开始。

第一次安装

01
完整解压下载包

保留 web-crawler-extension 文件夹。里面应该能看到 manifest.json。

02
打开浏览器扩展管理页

Chrome 地址栏输入 chrome://extensions；Edge 输入 edge://extensions。打开“开发者模式”。

03
加载扩展文件夹

点击“加载已解压的扩展程序”，选择包含 manifest.json 的文件夹。然后把“文字蜘蛛”固定到浏览器工具栏。

选定网页，或只选其中一块。

当前网页

打开目标网页，点击蜘蛛图标，再点“在当前网页开启”。

点击选块

移动鼠标查看范围，点击正文段落、代码块或内容区。

拖拽框选

按住鼠标画出一个矩形，松开开始。选择时按 Esc 取消。

抓取、翻转，也能随时恢复。

可以切换混合效果、抓取、翻转、反色、扭转、拉伸，并调节速度、力度、大小。网页右下角的控制条可以暂停、跟随鼠标、关闭并恢复。

使用自己的本地 HTML：在扩展“详细信息”中开启“允许访问文件网址”，再用该浏览器打开 HTML。

快捷键：Alt + Shift + S 暂停 / 继续；Alt + Shift + X 关闭并恢复。网页刷新后重新开启。解压目录需要保留。

适用于普通网页的主页面文字。浏览器设置页、内置 PDF、跨域 iframe 和图片中的文字不参与。
